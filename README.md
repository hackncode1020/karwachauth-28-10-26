# Karwa Chauth Moon 🌙❤️

**Mera chaand tum ho.** A Karwa Chauth surprise for your wife or husband, made with plain HTML, CSS & JavaScript (canvas, no libraries, no images).

🔗 **Live:** https://karwachauth-hackncode.sites.tab.bot/

## What happens
1. Type your love's name and press **Start 🌙**
2. A glowing full moon rises into the night sky
3. A decorated golden **chhalni** (sieve) slides over it
4. Through the chhalni the moon turns into a glowing heart
5. The screen writes **"Mera chaand tum ho 🌙❤️"** and **"Happy Karwa Chauth, &lt;name&gt;"**
6. Diyas flicker at the bottom, golden sparkles float up, all inside a mehendi-style border

Share a personalised link: `https://karwachauth-hackncode.sites.tab.bot/?name=YourLove` (with no name it says "my love").

## Files
- `index.html` – layout, name box, Start / Share buttons
- `style.css` – festive gold theme, mobile-first
- `script.js` – canvas animation: moon, chhalni, heart morph, diyas, sparkles, typing text

## Run it
Just open `index.html` in a browser. That's it.
